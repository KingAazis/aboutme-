Isinya index.html, folder media, dan data.json. Simpan ZIP ini sebagai cadangan.

  1. Ekstrak ZIP di komputer atau ponselmu.
  2. Buka Netlify Drop, atau repositori GitHub Pages milikmu.
  3. Unggah semua isi hasil ekstrak. Pastikan index.html dan folder media ikut terunggah.
  4. Untuk mengubah isi lagi, buka situsmu dengan menambahkan #admin di ujung alamat, edit, lalu klik Terbitkan dan unggah ulang.
